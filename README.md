# CyberShield

CyberShield is an AI-based cyberbullying detection web application designed to identify potentially harmful or abusive text and promote safer online communication.

## Objectives
- Detect potentially cyberbullying or abusive text.
- Analyze user-submitted text using AI or machine learning.
- Display clear and understandable analysis results.
- Promote safer and more responsible online interactions.

## Technology Stack
- HTML
- CSS
- JavaScript
- Python (backend)
- Machine Learning / Natural Language Processing
